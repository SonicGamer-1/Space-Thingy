# Space Game

A 2D arcade space combat game written in C++17 utilizing the **SDL2** library suite.

## 🚀 Features

- **Space Physics & Movement**: Smooth player movement with engine sound dynamics.
- **Combat Systems**: Projectile bullet physics with trail effects, enemy AI tracking, and enemy counter-bullets.
- **Audio System**: Background music (BGM) and embedded sound effects (SFX) managed via `SDL_mixer`.
- **UI & Font Rendering**: Custom health display, bullet inventory status, and real-time FPS counter using `SDL_ttf`.
- **Embedded & External Assets**: Support for external media assets alongside generated byte array headers.

## 🛠️ Prerequisites

To compile and run this project, you need:

1. **GCC / MinGW-w64** compiler supporting C++17 (`g++`).
2. **GNU Make** (`mingw32-make` on Windows).
3. **SDL2 Development Libraries**:
   - `SDL2`
   - `SDL2_image`
   - `SDL2_ttf`
   - `SDL2_mixer`

---

## ⚙️ Building & Running

### Using Makefile (Recommended)

- **Build the project**:
  ```bash
  mingw32-make
  ```
- **Build and run the game**:
  ```bash
  mingw32-make run
  ```
- **Clean build artifacts**:
  ```bash
  mingw32-make clean
  ```
