# Space Game

A 2D arcade space combat game written in C++17 using the **SDL2** library suite, supporting Windows, Linux, and Android.

## Features

- **Space Physics & Movement**: Smooth player movement with engine sound dynamics.
- **Combat Systems**: Projectile physics with trails, wall bouncing, enemy AI, and enemy counter-bullets.
- **Bullet States**: Player bullets have one remaining bounce and change from green to yellow; enemy bullets are red and do not bounce.
- **Cross-Platform Input**: Keyboard & mouse for desktop; accelerometer tilt steering & touch aiming for Android.
- **Audio System**: Background music and embedded sound effects managed with `SDL_mixer`.
- **UI & Font Rendering**: Health display, bullet inventory, and FPS counter using `SDL_ttf`.
- **Window and Rendering**: Resizable, DPI-aware SDL window with fixed logical 1600x900 rendering, OpenGL ES 2.0 on mobile, and vsync disabled.
- **Embedded and External Assets**: External music alongside generated byte-array asset headers.

## Prerequisites

### Windows

1. MinGW-w64 with C++17 support.
2. GNU Make (`mingw32-make`).
3. SDL2 development libraries:
   - SDL2
   - SDL2_image
   - SDL2_ttf
   - SDL2_mixer

### Linux

1. GCC with C++17 support.
2. GNU Make.
3. `pkg-config`.
4. SDL2 development packages:
   - `libsdl2-dev`
   - `libsdl2-image-dev`
   - `libsdl2-ttf-dev`
   - `libsdl2-mixer-dev`

### Android

1. Android Studio / Android SDK (API 31+).
2. Android NDK (version 21+; NDK 28 tested).
3. CMake (version 3.22.1+).
4. Java Development Kit (JDK 17+ or Android Studio JBR).

## Building and Running

The project supports Windows, Linux, and Android builds. Object files for desktop builds are kept separate under `build/windows` and `build/linux`.

### Windows

Build:

```bash
mingw32-make windows
```

Build and run:

```bash
mingw32-make PLATFORM=windows run
```

### Linux

Build:

```bash
make linux
```

Build and run:

```bash
make PLATFORM=linux run
```

### Android

#### Build the Debug APK

From the project root:

```powershell
# Using the Gradle wrapper
.\gradlew assembleDebug

# Or using Make
mingw32-make android
```

On Linux:

```bash
./gradlew assembleDebug
# or:
make android
```

Alternatively, from the `android/` directory:

```powershell
cd android
.\gradlew assembleDebug
```

The APK will be generated at:
`android/app/build/outputs/apk/debug/app-debug.apk`

#### Install and Run

Install directly on a connected device or running emulator:

```powershell
.\gradlew installDebug
```

Alternatively, open the `android` folder in **Android Studio** and click **Run**.

### Host Platform (Desktop)

Build for the detected host platform:

```bash
make
```

Clean generated build artifacts:

```bash
make clean
```

On Windows, use `mingw32-make clean`.

## Gameplay

### Controls

#### Desktop
- **WASD**: Move the spaceship.
- **Mouse**: Aim.
- **Left Mouse Button**: Fire bullets.

#### Android / Mobile
- **Tilt Device**: Steer spaceship using the built-in accelerometer.
- **Tap Screen**: Fire bullets in the direction of the touch.

### Mechanics

- Player bullets can bounce once:
  - **Green**: One remaining bounce.
  - **Yellow**: Zero remaining bounces.
- Enemy bullets are **red** and do not bounce.
- Health icons indicate remaining player durability.

## Rendering

- Fixed logical resolution: `1600x900`.
- Resizable window with logical game scaling.
- Nearest-neighbor logical scaling.
- Windows per-monitor v2 DPI awareness.
- Renderer vsync explicitly disabled.
